# About

This is an example sub-page. In Zola, the file `content/about/index.md`
creates the **/about/** page.

## How Zola organizes content

- `content/_index.md` → the site home page.
- `content/about/index.md` → the `/about/` page.
- Each file's front matter (the `+++ ... +++` block) holds metadata like
  `title`, `description`, and `date`, which templates can access.
